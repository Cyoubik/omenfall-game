# Omenfall

A card idle game with made-up gods, oaths, two prestige layers and mouse-drawn card art.

**Play:** https://cyoubik.github.io/omenfall-game/

Available in English and German; switch languages in the Chronicle tab.

## About

A hobby project: I simply pour my leftover Claude tokens into it. Claude, an AI by Anthropic, wrote the code and text, and drew the card art. Gemini by Google reviewed the design and translation. No money, no ads, no purchases.

## Privacy

No accounts, cookies, ads, analytics or requests to third-party servers. Your save stays in your browser (localStorage) and can be deleted completely in the Chronicle tab. GitHub, which hosts this page, may log visits like any web host.
